# 会话恢复与历史翻阅 · 2026-09-23

本轮按用户最新确认回到最初设计：Cozymate 只恢复同一条真实会话，不增加续聊提示或专用未读状态。

保留的 Figma 画板：

- `Cozymate / chat` — `246:1144`
- `Cozymate / history-loading` — `830:15`

实现规则：

- 每次进入或重新回到 Cozymate，都刷新当前会话；没有当前会话 ID 时发现当前账号最近一条真实会话。
- 恢复完成后定位到最新内容，同时保留未发送草稿和附件。
- 接近顶部时用排他的 `before_sequence` 游标加载更早消息，按持久化消息 ID 去重，并保持当前视口。
- 用户在本次访问中手动向上翻阅时，新回复不抢滚动位置，只显示普通“回到最新消息”按钮。
- 不显示“可以从上次的对话继续”提示，不显示新回复分隔标记，也不持久化阅读位置、未读状态或提示回执。

验证：

- Flutter：8 项会话恢复聚焦回归通过，相关文件静态检查通过。
- Agent Runtime：保留已有 owner-scoped 历史读取、分页、OpenAPI 与契约门；本次未修改 Runtime 实现。
- 设计契约 JSON 仅保留 `chat` 与 `history-loading` 两个会话恢复状态。
