# Agent 结构化表单

## 依据与修改

重新阅读 `agent/derived/form.md`、公共 Design System 和原设计 `UI.tsx` Modal、`styles.css` 1176–1179 / 2653–2660。原工程没有结构化表单独立稿；本页按用户已确认的统一规范补齐，并继续明确标记为衍生设计。

入口使用共享 Agent 结果卡，移除旧侧边色块和固定高度，长标题及状态可以换行。弹窗使用暖白表面、18标题与关闭按钮；展示原生已有的用途说明，按 schema 分组，标签/输入14、字段16间距、分组24间距，统一中性色分组标题。长下拉选项与日期允许完整显示；自定义选项补齐已选、可用及互斥语义。

空间充足时保持标题和操作区，短屏、键盘或大字号时整体可滚动；拖动收起键盘。校验或失败反馈按其实际位置滚入视口，不再假设错误始终在滚动内容最末端。输入、取消恢复、提交中关闭门禁、成功后只读查看均保留。提交方法自身补上锁定检查，避免同一帧或已完成后重复调用提交回调。
