## 对齐内容

- 预约前确认从正文卡片改为底部弹窗，沿用 ProductFlowDialog 的外边距、圆角、固定标题/关闭和可滚动正文。服务适用性及风险判断使用有标题的边框分组，风险选项保留整行可点击，紧急提示使用琥珀色卡片。
- 未选州、州不被实际专家支持、未确认适用性或存在紧急风险时不能继续。支持州来自 BookingContext.providers，不写死 CA；API 仍执行原有适用性检查。急救提示保留既有“联系当地急救服务”，不增改医疗判断。
- 时间页采用紧凑返回/标题、带日期与星期的整行控件、蓝灰专家预览、选择专家、时段数量和紧凑时段卡。保留专家时区及夏令时缩写，避免把不同时间误显示为相同本地时间。无头像 URL 时使用专家姓名缩写，复用 ServiceExpertIdentity，不绑定演示专家照片。
- 点击可用时段后先通过既有接口保留，再打开确认弹窗。摘要居中展示日期、时间、专家和时长；关闭弹窗保留该时段，可再次打开；“重新选择”通过原取消接口释放。倒计时与通知提醒是既有业务功能，继续保留，因此确认弹窗比设计稿略高。
- 确认预约沿用 expectedVersion。未收到确定结果时重试原操作与版本，忙碌时不能关闭或通过硬件返回退出。释放时段的重试成功会关闭弹窗；保留过期后不再出现确认按钮，也不额外取消已过期数据。
