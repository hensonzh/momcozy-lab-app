# 动作评估：衍生设计验收

依据 `common/derived/motion.md` 和统一主题，范围是用户 App 的 `/motion-assessment`。没有独立设计原稿，仍标记为衍生设计。

## 视觉与交互

- 暖色页头放在相机舞台外，标题和唯一的“结束评估”操作不再覆盖人体画面。2x 字号按“头颈姿态 / 动态评估”断行，辅助技术读取完整标题。
- 相机预览与骨架仍共享同一个舞台，保留原始坐标转换和识别语义。短屏上的取景轮廓等比例缩窄，避免人体被横向压扁。
- 失败态保留暖色卡片、一个主重试操作和次级退出操作；短屏内容可滚动。顶部结束按钮在失败或保存过程中禁用。
- 保留现有语音引导流程：准备、选项确认、采样、转身、复核和完成确认不新增操作面板。结果完成后仍返回 Agent 并携带结果刷新标识；后续 Agent 结果展示属于 Agent 条目验收。

## 验证证据

`regression.txt`：131 项动作评估相关测试通过，覆盖权限拒绝、相机初始化/推理失败、重试与资源释放、普通语音排空、实时语音失败恢复、多人/目标切换、分段采样、结果持久化、用户确认与取消、原生预览坐标变换及 Agent 入口卡片。

`layout.txt`：页头断行调整后的界面与控制器测试。金图包含 320/390/430 宽度、1x/2x 字号；2x 短屏为 320 高，验证可滚动访问失败操作。Android 截图补充实际竖屏 1x/2x 布局。

`native.txt`：Android 集成测试运行真实页面及控制器，依次验证拒绝权限 → 重试 → 相机失败 → 重试恢复取景引导 → 结束返回。检查拒绝权限时既不启动相机，也不创建服务端会话；检查页头与取景区域不重叠、按钮不少于 44、退出后释放资源。

Android 测试使用隔离的相机/语音/仓库夹具，不请求真实权限，不采集视频或音频，不调用外部评估服务。它证明实际 Android 界面与生命周期行为，不代表真实人体测量准确性或远程语音服务端到端验收；这些边界未因 UI 重构而改变。
