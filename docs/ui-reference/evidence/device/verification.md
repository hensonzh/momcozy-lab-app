## 功能与资源释放

- 用户打开检测弹窗后仅启动一次，请求中禁用重复启动。两个设备必须都可用；只有摄像头可用时不能显示完成。
- 检测结果读取后立即调用既有 close，释放摄像头、麦克风和音量监听；无需等到用户关闭弹窗。重新检查创建新轨道，不沿用上一次结果。
- 在权限请求未返回时关闭弹窗，既有服务 generation/dispose 保护会释放迟到的摄像头，且不再请求麦克风。相应资源清理有实际服务单元测试和页面测试。
- 工作台使用保留原实现的 ConsultationDevicePreviewDialog，仍手动开始并保留画面/音量预览。RoomPage 根据既有 isExpert 选择组件；没有为用户 App 暴露两个版本。此预览文件在工作台清单登记，不计入用户 App 验收数量。
