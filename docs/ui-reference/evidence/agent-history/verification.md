## 修改

- 使用共享 Agent 色彩和源设计 chat SVG，替换旧玫瑰色选中态、实心聊天图标和旧页头尺寸。当前行保持选中语义，长标题保留完整文本语义；日期采用浏览器参考的 M/d HH:mm，并继续转为本地时间。
- 列表切换锁定时按设计降低非当前行透明度；加载某条会话时所有行暂停交互，避免显示可点击却忽略操作。加载、失败和空状态保留独立反馈，失败内容可滚动。
- 关闭按钮维持 44 触控，面板保留系统返回、遮罩关闭和左滑关闭。原生作为真正的模态路由覆盖 App 并处理 SafeArea；不复刻设计浏览器中底部导航的 z-index 叠层差异。
- 修复 `onDismissed` 同时在 PopScope 和路由完成后执行两次：只通知一次，同时保留 PopScope 的即时通知，确保迟到的历史加载不能覆盖新会话。没有改变 API、历史能力开关和服务端会话数据。
