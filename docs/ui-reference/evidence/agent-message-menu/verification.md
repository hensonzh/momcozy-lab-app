# Agent 消息操作：衍生设计

重新阅读设计工程 `UserApp.tsx` 的 AgentPage 消息树。原稿没有消息菜单，按照用户已批准的统一规范补齐 `agent/derived/message-menu.md`，清单保持“衍生设计”标识。

## 实现和边界

- 用户正文、历史回复及当前已结束的回复通过同一组件打开轻量菜单：淡紫底、深紫字、14 圆角、细线图标，最小 44 触控。使用长按、右键、辅助功能操作或 Shift+F10；不在气泡上新增常驻按钮。
- 复制保留消息原文、换行及 Markdown。只复制用户实际选中的消息；没有正文的附件、默认问候和系统状态提示不提供复制。生成、停止请求及等待确认期间不开放当前回复的菜单。
- 重试使用原有 `canRetry`、显示条件和回调，不扩大可重试状态。历史文本没有重试/删除能力，因此不展示这些操作；原来的行内重试入口保留。
- 菜单支持系统返回、焦点恢复；复制成功和失败都有反馈。菜单打开期间消息内容或可用状态改变后，旧操作不再执行。正文长按不影响 Markdown 链接的点击或图片预览的点击。

## 验证

- `before.txt` 复现用户消息长按后没有复制入口。
- `component.txt`：14 项测试通过，包含 320/390/430 × 1x/2x 的 18 张菜单金图、选中消息完整复制、Markdown 原文复制、既有重试回调、流式状态限制、键盘入口/返回焦点、剪贴板失败和旧菜单失效。
- `regression.txt`：508 项 Agent、媒体、流式事件及共享组件回归通过。此前已有的图片、文件、Markdown 点击和会话状态测试保持通过。
- Widget 金图使用 Flutter 默认无阴影测试模式，阴影边界在此模式下显示轮廓；实际菜单阴影以 Android 截图为准，不将测试绘制的黑色轮廓作为产品设计。

Android 验证使用实际生产消息组件和系统剪贴板，重试为记录次数的本地回调。不会发送新消息，不代表远程模型回复恢复；Agent 服务鉴权问题仍由会话页面的待复核条目记录。

`native.txt` 最终通过：普通/两倍字号共 6 张实际菜单截图，系统剪贴板读回原文、系统返回后再次长按、重试一次均正确。已目视核对实际淡紫表面、阴影、图标、触控区域及大字号排版。

原生测试曾暴露长按菜单关闭后无法再次触发的现象。日志确认导航已处理返回，消息仍在前台且命中测试正确，但长按识别器未收到取消事件。Flutter LiveTest binding 默认丢弃 device-source 事件，恰好过滤了 Navigator 在推入菜单路由时生成的 PointerCancelEvent；在 Android 集成测试开启 `shouldPropagateDevicePointerEvents` 后复核通过。此调整仅位于测试入口，产品代码未增加手势延时或状态重置补丁，所有临时诊断输出均已移除。

`analyze.txt`：6 个相关文件无静态检查问题；最终 `component.txt` 为 14 项普通回归通过，金图没有重新放宽比较阈值。

`build.txt`、`install.txt` 确认普通本地 Debug APK 构建和覆盖安装成功。实际 App 当前没有历史正文，只有默认问候；通过 ADB 实际长按确认不出现复制操作（`native-app-greeting-no-menu.png/xml`），未为测试发送新消息。最终已返回保留登录状态的 Mia 首页（`native-restored-home.png/xml`）。修改未提交。
