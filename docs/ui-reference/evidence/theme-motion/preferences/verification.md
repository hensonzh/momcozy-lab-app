# 减少动态效果：首次使用、切换与程序定位

本轮重新阅读生活陪伴型 Design System、形象生成/审核衍生规范、媒体衍生规范和历史面板参考；仅调整非必要移动和过渡，保留对应页面的视觉状态与业务行为。

## 实现

- 新增 `MomCozyMotion`，统一处理减少动态效果下的时长和程序滚动。日记、Baby 资料/记录/首页、购买与 Agent 的显式平滑定位均接入；启用时直接到达反馈位置，普通模式保留原时长与曲线。
- 直接定位后，懒加载列表可能更新原先估算的内容范围。组件在布局后无动画校正目的位置，避免反馈留在屏幕外。
- 首次使用的候选形象与默认形象选中状态、任务横幅文案切换响应减少动态效果。横幅的尺寸动画直接跳过；不能仅把 AnimatedSize 时长设为零，否则此 Flutter 版本会在尺寸变化时产生布局重入异常。
- 会话历史与视频全屏在该设置下首帧即完整显示；视频播放器仍是同一实例，真实播放、暂停与返回行为保持正常。

## 证据

- `before.txt`：改造验证中捕获的 AnimatedSize 零时长布局异常及懒加载范围更新问题；已修正。
- `component.txt`：320/390/430 × 1x/2x，加普通滚动，共七项通过。检查任务状态切换时旧文案立即移除、候选选中边框立即到达最终状态、反馈定位与历史面板首帧位置；普通模式仍有中间滚动位置并最终到达目标。
- `regression.txt`：308 项相关检查通过，包含首次使用、媒体、Agent、日记、Baby 和购买状态。金图位于 `test/goldens/design_system/reduced-*.png`。
- `native.txt`：Android 1x/2x 选择、任务状态、反馈定位与历史操作通过；该夹具使用内存仓储，不写入账号资料或会话。
- `video-native.txt`：实际 Android 播放器通过本地 HTTP 读取 MP4，验证携带授权头、播放进度、暂停、首帧全屏完成、退出全屏和返回释放。系统减少动态效果通过测试平台配置注入；未请求外部媒体服务。
- `analyze.txt`：16 个实现与测试文件静态检查无问题。截图在状态断言后等待布局和测试触点标记结束再采集；`native-reduced-feedback-2x.png` 已确认反馈文字实际出现在屏幕内。
- `build.txt`、`install.txt`：普通 local APK 构建并覆盖安装成功，测试入口已替换回正常 App；Mia 登录首页恢复，见 `native-restored-home.png`。本轮没有保存任何真实记录、头像或会话。

首次使用和历史的截图只用于本轮状态/过渡验证，不是新增原始设计稿。历史页整体仍需复核，包括长会话标题、分组、真实历史能力与服务端交互；不把内存会话选择当作真实后端历史验收。

后续已验证普通路由与通用弹窗/底部弹层，见 [路由验证](../routes/verification.md)；日期/时间入口见 [选择器复核](../pickers/verification.md)。Typography 覆盖关系继续保留在公共 Theme 待办中。
