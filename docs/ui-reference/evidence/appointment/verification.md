## 对齐与业务边界

- 详情页使用紧凑的返回/居中标题/分隔线，16 正文边距。预约卡片采用 17 内边距、绿色日历图标、紧凑时间、分隔线、实际专家身份和浅玫瑰色取消按钮。
- 预约管理页和独立预约详情复用 AppointmentDetailCard、AppointmentCancelDialog 及 ServiceFlowTheme 的按钮规范。原 AppointmentSummary 留给咨询室使用；工作台也使用该咨询室，因此本轮没有更改它的摘要组件。
- Native 预约实体没有服务包名称、咨询序号或专家头像字段，显示实际预约状态与 IBCLC 咨询说明、实际日期/时间/时区和姓名缩写，不填入设计稿的演示服务名称或专家照片。保留时长与时区，避免跨时区误读。
- 既有信息采集、咨询准备、服务详情和通知提醒入口继续可用；这些额外入口使原生详情页比设计单卡片更长。提醒控件沿用原通知协调器，文案与字号和当前中文用户页面一致，不变更开关和权限逻辑。
- 取消确认改为共享底部弹窗，包含预约时间、专家、取消说明及保留/确认按钮。大字号时操作纵向排列，标题保持可见、正文可滚动。短屏和安全区下仍可触达确认按钮。
- 取消处理中锁定关闭、硬件返回和重复提交；失败后保留原预约版本，重试同一请求。另可读取服务端预约核对状态：已取消直接完成；已开始则移除取消能力。未确认结果不会显示取消成功，返回按钮也不会误称“保留预约”。确认取消成功后回到原入口/Me。
- 返回信息采集或咨询页面后重新读取预约；后台恢复和路由参数变化会更新数据。读取失败提供重试，避免继续展示旧状态下的操作。
