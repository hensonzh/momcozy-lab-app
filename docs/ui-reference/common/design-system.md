## 验证与限制

全局规范已完成复核，最新结论与逐项证据见 [公共设计系统验收](theme-completion-audit.md)。未完成的业务页面仍按 page-map 独立保留。

- 设计实测值和原始截图保存于 [capture-manifest.json](../capture-manifest.json)；完整滚动图只扩大滚动容器，原始 viewport 另存。
- Android 字体由应用内 DM Sans / Manrope 和 Noto Sans SC 回退呈现；浏览器的系统字形可能有细微差异。不能仅凭同字号断言视觉一致。
- 每页的 Completed 仍要求独立运行、功能验证和截图比较；公共 Theme 调整不自动完成依赖页面。
- 减少动态效果：Agent 装饰、首次使用选择/任务切换、历史/视频全屏和程序定位已补齐，见 [证据与剩余审计](../evidence/theme-motion/verification.md)。普通路由、公共弹层和日期时间选择器已补充验证，见 `evidence/theme-motion/routes` 与 `evidence/theme-motion/pickers`；局部排版审计已完成，见上述公共设计系统验收。
- 段落样式：`MomCozyTextRoles.paragraph` 为用户 App 公共加载、空状态及错误说明提供 1.55 行高；控件与工作台保留原有度量。详见 [正文验证](../evidence/typography/reading/verification.md)。局部正文与原稿特例已复核，Theme 已完成；其它业务页面不随之自动完成。
- Cozymate 的普通回复与 Markdown 正文统一保留 16 / 1.65，Markdown 一级至三级标题为 17 / 1.5，链接为紫色下划线；等宽代码保持独立阅读度量。已移除 Markdown 强制覆盖为 1.42 的旧样式，见 [Markdown 排版验证](../evidence/agent-markdown/verification.md)。首次使用的照片隐私、生成阶段、等待及启用说明已统一为 1.55，见 `evidence/onboarding-reading`。
- 登录参考使用用户 2026-09-12 确认图，来源记录在 [login.md](../auth/login.md)。其它认证/首次使用流程按用户确认建立衍生规范，明确标注来源；参考齐备不代表已实现或已验收。

## 已提取的一级页局部规范

- Agent 附件：菜单与消息附件的 camera/image/file 线图标取自设计 UI.Icon（1.8 描边）。待发送图片和文件复用 `AgentAttachmentTile`，统一缩略图/文件名/大小与 44 移除目标，在同一横向区域排列。大字号菜单以整个输入框为锚点，避免覆盖展开草稿。原生文件能力仍为 PDF / 10 MB，说明据实际契约显示，见 `evidence/agent-attachments/verification.md`。

- Cozymate：奶油紫底叠加右上淡紫与左侧浅桃渐变，文字 `#352D40`，交互紫 `#7943B5`；助手气泡左上 6 / 其它角 22、内边距 16，正文 16 / 1.65；输入栏圆角 24、高至少 56。快捷提问仍经现有消息 runner 发送；动态推荐回复维持既有开关。
- More：16 外边距、账号卡 12/10 内边距、16 圆角、44 头像、17 昵称与 11 邮箱。通知、账号设置、专家支持和退出属于保留原业务入口的衍生补充，采用设计 `menu-list` 的 48 最小行高与细分隔线。账号显示来自现有账号与 profile 接口，不展示内部 user ID。
- 日程：居中 17 月份、10 说明，按当月实际周数排月历，45 最小日期高度；真实 active 服务起止日期映射 `#DFEEE8 / #A9CDBF / #315E50`。事件使用平铺列表；添加按钮 44、圆角 14，固定在导航上方。

小屏或放大字号允许增加高度与换行；快捷提问和服务筛选的点击区扩至至少 44，区别于 Web 稿中 30–36 的紧凑点击区。

- 日记面板采用局部深棕/奶油规范：页头 `#3B2C23`、正文 `#49392F`，字段 `#FFFAF6`，选中 `#EADBCC / #9D8471`。`ChoiceFieldStyle` 的 warmTiles/warmSegmented 与默认 chips 共用选择及互斥逻辑；默认 chips 外观保持原样。对话框背景为 `#30272355` 加 2px 模糊，键盘或矮屏收起辅助页头，保留分类、滚动字段与保存按钮。

- 记录选择：340 最大宽、22 圆角、22 内边距；暖色 `#FBF7F2` / `#F1E7DD`，两个入口共用 16 主标签与 11 说明，关闭扩大至 44。无需重新创建日记或泌乳业务流程。
- 知识详情：复用同一个 `showKnowledgeArticle`，Me 使用底部浅色弹窗，Baby 使用淡紫渐变页头；正文序号、细线、来源、内容边界和 Cozymate 操作保持顺序。为保留真实来源与小屏可用性，正文滚动、CTA 固定；Baby 最大高度 700，仍受 88% 视口约束。
- 认证衍生页面：注册、验证、找回、重置复用 `authLoginTheme` 与 `AuthLoginHeader` 的紧凑变体。输入框/玫瑰主按钮/品牌字体遵循用户确认登录稿；同一步骤保留字段草稿，切换步骤关闭键盘并回到顶部。正常消费登录不加入内部邀请码。
- 泌乳：218 顶图（窄屏 190）、深棕趋势、独立泵奶/亲喂统计与轻量记录行。编辑器采用连续字段、分离侧别按钮、常驻单位、可展开备注，原生触控至少 44；时间与数值范围仍由既有 domain/controller 校验。

- 专家服务：复用 `ServicePackageFacts` 与价格展示，蓝灰团队入口、绿底已购方案、细线交付列表；44 触控、18/20 卡片圆角、浮动底部操作在大字号时纵排。真实接口无头像时用中性图标。
- 首次使用衍生流程：复用登录暖白底/DM Sans 与 Libre Caslon 标题、玫瑰主按钮、16 表单边距，说明改为标题下连续文字。步骤切换保留草稿并重置焦点/滚动；反馈使用共用组件。

### 宝宝记录与资料弹窗（2026-09-12 逐页复核）

- 以 baby.css 的暖色表单为准：最大宽度 440、暖米白表面、深棕页头、22px 标题与圆形关闭按钮；统一实现为 `WarmEditorHeader`。长宝宝称呼最多两行，保持关闭可用。
- 状态记录采用固定高度上限 720 与固定保存区，内容独立滚动；键盘占用时由 Dialog 可用空间约束。资料页保存按钮也固定，失败后滚动到反馈。
- 选项复用 `ChoiceField.warmTiles / warmSegmented`；颜色标记通过可选 `optionIcon` 呈现，并保留文字标签。大字体自动减少列数，不用颜色作为唯一表达。
- 时区日期控件沿用原来的日期/时间/夏令时逻辑，仅新增暖色呈现；数值单位在空值时也保持可见。补充备注折叠后保留草稿。
- 宝宝切换入口是独立的无障碍按钮，避免把邻近性别、月龄信息合并进点击区域。切换器保留真实的“添加宝宝”入口；资料保留“暂不填写”和喂养方式设置。

### 个人日程与任务菜单（2026-09-12 逐页复核）

- 日程新增/编辑以 PlanPage 原稿的白底底部弹窗为准：24 圆角、最大宽 440、高度上限 560、20 内边距、18 标题；共享 `_ScheduleDialogFrame` 同时用于删除确认。
- 字段顺序为名称、日期/开始时间、备注；宽屏日期与时间两列，小屏及大字体纵排。保存区常驻，极矮键盘视口改为连同内容滚动。
- 新增和编辑在服务确认成功后关闭；失败保留草稿，结果不确定时冻结输入并用同一幂等键重试，防止重复新增。关闭已修改草稿保留既有确认交互。
- 删除确认展示真实日程名称、日期与开始时间；“保留日程”为主操作，“确认删除”为危险描边操作，大字号下纵排。
- 专业任务是行内状态菜单，白底、11 圆角、暖灰细边；状态操作和“查看服务计划”保持既有业务契约。原稿 36 高触控项扩大到 48，正文 12，以支持移动端点击和字号放大。

- 正在睡眠采用居中月亮图标、宝宝称呼、开始时间和已记录时长，保留底部结束操作；已有时间及备注调整通过次级文字入口展开，收起不清空草稿。宝宝资料长标题常态最多三行，键盘出现收紧为一行，将空间留给可滚动字段和固定保存区；完整称呼保留在输入框和语义文本中。

### 宝宝保存与校验反馈（2026-09-12）

- 紧凑校验条使用 recordValidationSurface / recordValidationInk 语义 token，9 圆角、9/10 内边距、11 字号和 liveRegion，保留原表单校验条件。
- 保存反馈是首页的绿色 14 圆角区域，包含确认、撤销和 44 关闭按钮；小屏将操作置于文案下方。失败改为琥珀色并保留待确认对象；提示属于保存的记录与版本，不跨宝宝复用。
- 缺失生长资料时只呈现完善资料引导；没有曲线时不显示曲线说明。小屏的体重/身长/头围切换平分整行，正文允许随字号增长。

### 首页预约准备弹窗（2026-09-12）

`ProductFlowDialog.expert` 复用通用可滚动弹窗框架，采用当前 expert-appointment-dialog 的 360 最大宽、18 圆角、19 标题、expertSurface/expertBorder 和 44 触控关闭图标。遮罩使用 expertDialogBarrier（#202b3155）；大字号纵排日期、倒计时与操作。进入取消或设备确认时隐藏准备面板，保留真实首页背景；咨询连接成功后同一控制器呈现全屏咨询，关闭和跳转时统一收起其嵌套弹窗。独立房间路由与首页入口共享准备内容，没有另存一套旧准备布局。
