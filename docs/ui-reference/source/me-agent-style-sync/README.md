## 数据与发布边界

保留现有专家身份、头像、真实记录、权益数量及咨询流程；不复制参考的虚构专家分配或服务文档。没有真实记录的日期不生成曲线数据。主导航保持之前要求的跨模块稳定样式。

Web 发布使用无秘密文件的固定源码归档与 SHA256，远端继承上一版后端和部署配置。只构建并替换 `consultation-web`，预检失败不切换，替换失败恢复旧镜像。保留旧发布目录与镜像，无数据库迁移，不需要数据库备份。

公网预检发现原有 Google Fonts 外链在受限网络下阻塞首屏。现将原有 DM Sans / Manrope 字体、字重与字符子集本地托管，保留 OFL 授权文件；不更换字体。自动化布局检查等待字体与渲染帧稳定后再测量，避免把字体加载中的过渡帧误判成稳定布局。

旧部署的共享环境文件没有保存 `CONSULTATION_TEST_PUBLIC_IP` / `CONSULTATION_EDGE_BIND_IP`；发布时需使用当前运行配置中的值。发布脚本会在构建和替换前先校验完整 Compose 配置，不修改这些网络参数。

发布前发现的原有限制：线上 `POST /api/agent/threads/.../turns` 返回 404，既有静态 Web 部署未提供本项目 Vite 对话适配器；本次 UI 发布不更换服务端或模型配置。Agent 的错误/重试以本地模拟 SSE 验证，不能据此声称线上真实模型对话已通过。测试站点仍使用内部 CA，真机与弱网不在本轮验收范围。
