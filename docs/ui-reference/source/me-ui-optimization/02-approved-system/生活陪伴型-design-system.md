# Me 模块视觉系统：生活陪伴型

## 定稿方向

以「柔和秩序」作为信息骨架，以「轻盈日记」控制表面质感。目标不是把界面做得更“可爱”，而是让产后妈妈在疲惫、分心或焦虑时，仍能快速理解当前状态与下一步，同时感到被温和陪伴。

## 设计原则

1. 内容和状态先于装饰；每屏只保留一个主要视觉焦点。
2. 先用位置、间距、字号和分组建立层级，再使用颜色与容器。
3. 卡片只表达真实边界，避免卡片套卡片；长表单优先使用分隔线和分组。
4. 红色只表示危险、错误或破坏性操作；倒计时、设备检测、等待和连接状态不用红色。
5. 所有操作闭环必须包含可用、处理中、成功、失败和恢复方式。
6. 生图只探索视觉语言；真实业务文案、数据、选中态和可用态以代码为唯一来源。

## 排版与密度

- 字体：中文使用系统无衬线；数字与拉丁文字使用 Manrope / DM Sans 回退。
- 一级标题 28–38px；页内模块标题 16–18px；正文 12–14px；辅助信息 10–11px。
- 正文行高 1.55–1.7，避免产后疲劳场景下文字拥挤。
- 页面主节奏 14–16px；组内节奏 8–12px；关键触控目标不小于 44px。

## 形态与层级

- 主卡片圆角 18px；紧凑控件 10–12px；状态胶囊使用全圆角。
- 默认卡片为 1px 暖灰描边 + 极弱阴影；弹窗可使用中等阴影。
- 主操作为深可可色实心按钮；品牌按钮只在明确的品牌选择语义中使用玫瑰色。
- 选中态同时使用颜色、边框和控件形态，不能只依赖颜色。
- 禁用态降低对比但仍保留可读标签与原因。

## 关键场景规则

- 首页：问候与当天状态为主；专家支持与产后服务按任务顺序下沉。
- 表单：使用连续分组与分隔线，选项保持可扫读，不引入额外插画。
- 预约：日期、专家、时段形成单一选择序列；已占用时段明确标注且不可选。
- 支付：安全信息使用鼠尾草绿，价格与支付动作保持唯一焦点。
- 咨询准备：倒计时和设备检测使用绿色、蓝色；正式开始前只确认当前位置。
- 视频等待：深可可灰视频区，等待使用绿色或蓝色，红色仅用于离开/结束。
- 隐私授权：说明对象、包含内容和用途，状态必须与真实勾选值一致。

## 验收条件

- 在 430px 设计宽度和 320–390px 窄宽下无裁切、重叠或横向滚动。
- 键盘焦点清晰，减少动态效果设置下不执行非必要动画。
- 业务文案、数据、按钮语义、选中态和可用态与优化前完全一致。
- 正常、空、禁用、错误、成功、弹窗和视频等待状态均可辨识。
