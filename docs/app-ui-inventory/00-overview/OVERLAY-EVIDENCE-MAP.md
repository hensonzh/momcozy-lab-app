## 归并边界

- Tooltip、AgentMessageMenu 或知识卡类型出现在背景树中，不代表浮层已经打开；本表引用具名展开／关闭状态。
- 宝宝切换、咨询离开、通知说明、语言选择、账号确认和放弃草稿原先候选数为 0，是扫描规则未识别；现有图已在上表对应，不新增截图。
- 系统窗口由原生截图与 XML 证明，不拿 Flutter 空占位代替。
- Agent 表单等改版内容以 [当前交付与复用](AGENT-CURRENT-REUSE.md) 为准；历史操作链保留入口证明，不把旧图升级为当前版。
- 相同图的多个入口与不同关闭方式共用代表图；确认后进入的详情页仍归独立页面清单。
