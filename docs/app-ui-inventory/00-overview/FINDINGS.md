## Baby 真实路由采集复核

- 记录保存失败可能进入“结果未确认”并锁定编辑控件，点击“重试确认保存”后才解除；删除/恢复也具有独立未确认与重试状态，已实际捕获。
- 输入提示动画和懒加载资源会影响截图时点。本轮修正测试等待与资源准备，不改变产品 UI。
- 根导航弹窗与嵌套页面可同时报告 isCurrent，必须区分最上层 PopupRoute；六个 Baby 滚动弹窗已输出完整内容。渲染根节点为 RenderView，不能仅通过 RenderRepaintBoundary 类型判断根截图边界。
- 服务端派生字段是 JSON 契约的一部分。模拟生长/发育响应缺少 unit/label 会被真实 codec 拒绝；模拟响应已补齐，并强化保存后的实际界面断言。
- Baby 历史的 51 条记录分页已经过失败与重试，最终长图为 393 × 9164，首条、末条及数据来源区域均可见。

## 咨询真实路由观察

- 用户暂时离开不会结束咨询，返回进行中的预约后仍有“返回咨询室”；本轮请求记录断言未调用专家结束接口。
- 入会请求失败保留待进入状态；房间轮询可以重试恢复。服务端撤销视频授权后，会断开媒体并恢复准备页。
- 已发布总结的任务标题是正文；“查看怎么做”打开行动详情，服务进度入口位于“咨询与服务信息”展开区。
- 行动更新失败保留原进度并禁用选择，提示结果未确认；点击重试后才取得完成状态。
- 咨询技术失败的重约入口会打开新的预约前确认；未出席必须未加入且超过截止时间；正常完成与安全升级都会进入总结整理中。
- 对应实际截图、规则来源和设备边界见 [咨询入口补验](CONSULTATION-JOURNEYS.md)。


## 通知入口与原生设置观察

- 归档/全部已读失败共用刷新错误标题；状态保留，用户可重试原按钮。
- 系统权限关闭时服务分类偏好仍可显示开启，伴随后台不可用说明；这两个业务维度不能混同。
- 目标失效的消息会标为已读并显示 Snackbar，有效消息则实际进入预约详情，返回后未读角标更新。
- 当前 Android 本地构建实际显示后台推送不可用，系统总开关为关闭。已从 App Settings 正常进入系统通知设置并返回，未改设置。
- 新增证据及尚未覆盖分支见 [通知入口补验](NOTIFICATION-JOURNEYS.md)。

## Cozymate 消息菜单与系统授权

- 当前源码在 Cozymate 消息菜单收到系统返回时抛出路由层 TypeError；菜单保持，点击外部可关闭。当前 Android 安装版同一操作退出到桌面，重开仍保留消息与草稿；两者根因尚未证实相同。
- 取消首次相机权限弹窗后，App 报“图片上传失败”，尽管没有选择图片或上传；相机授权值及 flags 前后不变。
- 默认历史入口未开启；生成的三项快捷回复在实际页明确隐藏。不能将这些组件预览计为默认可达路径。
- 长对话拼接保留全部正文，固定背景渐变存在接缝；大字号长单词和导航换行保留真实表现。详细截图、路径与边界见 [AGENT-JOURNEYS.md](AGENT-JOURNEYS.md)。

## Cozymate 表单重试与动作失败

- 确认或拒绝返回 503 后按钮消失，没有当前可点击的重试入口；Tab 往返保留失败结果。
- 表单同一幂等键重试成功后仍保留失败回复和两条已提交气泡。
- 记录卡片的中文 CTA 在 Widget 截图出现缺字方块，源码样式未显式设中文 fallback；原生设备表现尚未验证。点击真实 Text 标签可以进入记录页。
- 小屏大字号日期选择器会自动采用输入模式；记录页关闭先回妈妈页，再点 Cozymate 恢复对话。
- 59 个状态、具体路径与验证边界见 [业务流程补验](AGENT-WORKFLOWS.md)。


## Cozymate 语音状态与键盘短视口

- 切到 More 不取消当前播报，返回仍为原播放会话；关播报才取消。重新打开不会自动重播已完成回复。
- 流式播放失败后，新增 SSE 文字可自动启动新会话，仅朗读新增后缀；run 完成且无新增文字时通过错误提示手动重播全文。
- 键盘占位及 2x 字号下对话区可缩到 77px，“回到最新消息”覆盖较大区域。旧采集器跳过此短视口，本轮已修正并补齐全文；整像素滚动消除细条拼接的文字抖动。
- 本轮隔离播放器，不把页面播报指示当作真实音频输出成功证据。30 个状态及完整边界见 [语音补验](AGENT-VOICE.md)。

## 指定 Cozymate 会话通知初始化错误

实际通知 → `/?conversationId=<UUID>` 导航成功，但默认 Agent 页面将 String 用作 Expando 缓存键，初始化抛 ArgumentError，未请求历史接口。通知仍已读。More → Cozymate 可以恢复不带参数的默认页。无效 UUID、额外参数或外部 URL 则留在通知页并提示资源不可用。[错误、恢复、源码与限制](AGENT-TARGET-ENTRY.md)。本轮只记录事实，没有修改产品行为。


## 隐私授权实际交互

- 撤销确认中的“继续保留”仅取消本次提交，页面开关仍是待保存草稿；没有直接恢复已保存的开关值。
- 服务切换确认中的“放弃并离开”实际切换服务，页面仍在隐私设置；“继续查看”将选择器恢复到原服务。
- 多项授权第一项成功、下一项失败时，后续重试只提交未确认项；重新读取则放弃未确认草稿。
- 从通知设置返回保留草稿；隐私页放弃并返回 More 后再次进入使用服务端值。
- 320/2x 下闭合的服务选择器裁掉日期，打开下拉可见完整内容。

[实际窗口、长图与边界](PRIVACY-JOURNEYS.md)。本轮不改变产品行为，也未操作真实账号授权。

- 已结束服务的“继续支持”可从妈妈首页服务进度实际进入；新购服务与原已结束服务相互独立，往返路线已验证。

- 无参数续购路由受 Agent 通用内部导航识别，但来源卡片运行链仍未执行，不能据静态查找标为无入口或已覆盖。
