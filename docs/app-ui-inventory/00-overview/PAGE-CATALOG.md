# 独立页面总清单

本清单是面向浏览和补图的页面入口；原始批次和截图均保留。页面、状态、字号和入口不再混为同一个计数。

独立路由页面归并路由别名；/login 五个表单步骤分列；同一页面数据状态不计为新页面；Navigator 视频全屏单列；弹窗归属宿主页面。
