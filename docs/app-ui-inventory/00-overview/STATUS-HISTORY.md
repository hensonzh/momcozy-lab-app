## 为什么时间过长

1. 把 UI 盘点过度扩展成网络错误、重试、幂等请求与并发边界验证；其中部分不会产生新的独立视觉状态。
2. 相同页面在多条路径、多个尺寸和多次刷新后重复保存，历史记录和当前有效页面混在索引中，数量快速膨胀。
3. 先持续增加采集测试，再反复做分段像素审核；没有先形成固定的“独立页面 × 有意义状态 × 入口”总清单及逐项完成标记。
4. 工作区页面在期间发生更新，造成一些旧图重新核对。该因素有影响，但不是无限延长盘点的理由。

这是执行范围和收尾方法的问题，不能以严格测试或大量截图代替最终交付。目前没有可靠分母，不提供虚假的百分比或完成时间。
