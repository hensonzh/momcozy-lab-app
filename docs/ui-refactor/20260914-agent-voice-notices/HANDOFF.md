# 语音播报与附件失败提示

核对了 [77 个已有截图状态](source-inventory.json)，包括语音失败、重播、播报开关、播放结束与切页，以及附件选择、上传、清理、取消和返回。新增 [27 个 Figma 画板](figma-nodes.json)，实现语音恢复卡片、播报头像提示色和附件失败反馈；其余状态复用已完成的聊天、附件和 More 页面设计。具体新增／复用边界见 [逐状态覆盖](coverage.json)，没有把所有状态计作新页面，也没有把组件测试当作完整旅程重放。

[Figma 普通语音失败](https://www.figma.com/design/ePIoJkiMiXiug9ibpcgRbl?node-id=267-1086) 沿用妈妈页的表面、边框、22 圆角和 NotoSansSCHome。提示正文从原来的 11 字号提升为 13 字号，保留完整原文；“播放回复”使用薄荷色按钮，关闭按钮独立保留 44 触控区。流式回复尚未完成时，重播仍保持禁用。设计覆盖普通／大字号、键盘上方布局及播放状态；在短屏迭代中确认提示、重播、关闭和输入框均可完整使用，见 [大字号键盘](figma/large-keyboard.png) 和 [流式失败](figma/stream-error.png)。

附件的图片上传失败、文件上传失败、文件过大、不支持格式、清理失败五类提示，复用已完成消息反馈的深色底和浅色文字，采用 14 字号、16 圆角及零阴影，见 [大字号清理失败](figma/large-cleanup.png)。保持原有提示文案、持续时间和滑动关闭方式。播报中的头像提示环改为共享玫瑰色，保留原有动画、视频资产、播放与取消逻辑。

验证结果：

- [241 项联测通过](joint-tests.log)，未启用更新基线。覆盖语音播放、播放协调与 API、媒体语音解析、Agent Hub 主流程、附件、消息菜单、图片和文档选择、通知会话路由及底部导航。
- 增加普通／大字号播放与重播指示检查，并完成 [21 项最终设计与行为检查](design-final.log)，未更新基线。此组与前述联测有重叠，不应直接相加。
- 键盘场景验证重播与关闭按钮至少 44 触控区、重播入口位于可用视口内；点击重播后确实再次调用播放器，再次失败后仍可关闭。播放指示检查确认失败时消失、重播时恢复、播放完成后消失；两次播放文本相同。
- 新增 10 项附件失败检查，通过真实 AgentHubPage 的附件入口触发五种提示，验证失败不会丢失输入草稿、验证失败不调用上传、内部异常信息不展示、滑动关闭提示后草稿仍保留，以及清理失败后再次成功清理。不是直接挂载一个静态提示组件。
- [4 个修改文件静态分析通过](analyze-final.log)。[三项行为对比通过](behavior-checks.json)：Agent Hub 差异仅限三个反馈构造调用及其样式和播报环颜色；语音提示文案、重播／关闭回调及 live region 保留；既有消息菜单实现未修改。
- 保存 [51 张当前验证图](verified-images.json)。目视核对普通流式失败、键盘大字号、附件清理失败与播放指示，并与 Figma 代表图对照。更新前检查发现语音旧基线仍包含重构前聊天外观，见 [首次检查](before-tests.log)；该失败运行已停止，之后按当前设计核对并更新基线，最终上述检查全部通过。
