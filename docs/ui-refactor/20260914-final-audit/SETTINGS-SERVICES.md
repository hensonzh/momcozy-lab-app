## 复用与边界

状态记录中的布局图和补充图有些用于证明共用控件、提示或页面结构，不声称每条原始操作链都在本轮重放。所有 source evidence 保留原触发说明。没有把归档节点存在、测试文件存在或源图存在单独当成验收通过。

- 目录沿用待付订单优先，详情沿用已有 episode 优先；保留原业务差异。服务阶段来自数据，不从过期日期或耗尽次数推导阶段。
- 通知跳转仍进入原业务目标，不新增通知详情页；账号退出后的登录、信息采集“稍后”的预约、预咨询的 Cozymate 分别复用对应目的页交付。预咨询的旧紫色聊天源图不作为新版视觉基准。
- 独立预约的咨询中、完成和加载状态使用最终盘点已有的复用渲染证据；三个 PNG 路径均已核实。它们不等于新增原生入口采集。
- 共享取消弹窗保持当前预约版本、未知结果查询和开始咨询后的限制；恢复为咨询中不计为取消成功。完成信息采集的“稍后”不计为预咨询完成。
- 系统权限、键盘、日期控件和真实付款服务维持原运行边界；本轮未执行真实付款、原生重新采集、构建或发布。
