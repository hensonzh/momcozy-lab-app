## 明确复用及运行边界

`direct` 表示对应布局/状态有直接设计与渲染证据；`shared_control`、`shared_notice` 表示共享控件或提示的组合复用，记录列明实际代码依据。布局参考图不冒充该状态完整操作链的重新执行。认证各步骤共用 `_run`、`_busy`、字段校验和 `AuthNotice`，同时保留步骤自己的请求、标题、文案和返回规则。
