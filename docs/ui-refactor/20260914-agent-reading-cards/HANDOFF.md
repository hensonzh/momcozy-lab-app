# 聊天阅读与资料入口卡片

完成 [21 个已有截图状态](source-inventory.json) 对应的正文标题、段落、列表、链接，以及资料、评估、咨询和表单入口卡片设计。先在 [Figma](https://www.figma.com/design/ePIoJkiMiXiug9ibpcgRbl?node-id=271-1510) 完成 [26 个状态画板和 1 个共享组件](figma-nodes.json)，再实现 Flutter。新增共享组件为 MomCozy/AgentResultCard（271:2179），普通和大字号均有设计，包含咨询同意后的可用按钮状态。

正文保留 16 字号与 1.65 行高；Markdown 标题调整为 18 字号、1.4 行高，与强调文字一起采用 NotoSansSCHome。链接使用青色下划线，列表标记与正文保持相同文字色。解析、链接识别与媒体分派保持原机制。代表设计见 [正文](figma/markdown.png) 和 [大字号链接滚动位置](figma/large-link.png)。

结果卡片复用 MomSettingsCard，采用 16 内边距、22 圆角和共享边框。标题为 16 字号，正文从 11 提升到 14 字号；图标区为 40×40，说明移到标题下方使用完整宽度。资料按钮为 13 字号、至少 44 高、薄荷底与青色文字，保留原图标及动态标签。普通字号卡片与聊天回复正文对齐，大字号使用可用宽度，见 [多资料入口](figma/multi.png)。字体统一解决了旧组件检查中部分中文按钮缺字的问题。

咨询卡片将顾问身份与简介组织为独立信息区，保留原有服务资料和协议文案。勾选同意后，服务入口采用玫瑰色主要按钮；取消同意或缺少回调时仍不可用。表单入口沿用相同标题和说明层级，图标、加载色及点击区域圆角与共享卡片一致。完整表单弹窗将在后续单独处理，当前只更新入口外观；[大字号同意状态](figma/large-consent.png) 已覆盖按钮可达性。
