通过 Figma 实际读取咨询和返回页面的节点、内容与尺寸，见 [读取记录](figma-readback.json)。重新查看 [大字号断线](figma/large-disconnected.png) 与 [短屏行动进度](figma/short-large-progress.png)。预约详情、专家身份、时间卡、总结主行动、服务记录时间线、日程和弹窗沿用现有设计体系。英文服务内容与时间属于测试数据，不改写为设计稿中的示例内容。
