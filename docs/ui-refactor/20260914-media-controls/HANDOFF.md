# PDF 阅读控件与视频播放器

完成 [19 个已有截图状态](source-inventory.json) 对应的 PDF 翻页／缩放工具栏和视频播放、暂停、静音、进度与全屏界面。先在 [Figma](https://www.figma.com/design/ePIoJkiMiXiug9ibpcgRbl?node-id=291-1086) 建立普通、大字号、短屏和横屏设计，再落实到 Flutter。[30 个节点](figma-nodes.json) 包含 28 个状态画板及两个共享组件：MomCozy/PdfDocumentToolbar（293:1224）和 MomCozy/VideoControls（293:1241）。

PDF 工具栏使用 Mom 浅色表面，将翻页和缩放分组；页码为 13 字号，按钮为 44×44、薄荷底色，大字号时分成两行。文档画布背景沿用妈妈页奶油色，文档自身的内容与字体保持原样。页码及缩放仍由现有 PDF 控制器计算；验证图中的 reset 指缩放比例恢复，不表示回到第一页，多个页面同时可见时仍沿用控制器的当前页规则。

视频将画布与底部控件分开布局，避免按钮遮住视频内容。页面内控件使用浅色表面，沉浸全屏保留深色控件区域；播放按钮为玫瑰色，其他操作使用薄荷／深色底。13 字号播放时间在大字号下独立成行，按钮触控区至少 44×44。加载、失败及全屏播放中断复用已完成的媒体反馈卡片，并保留原来的重试及返回文案。

本轮修改四个生产文件及两个测试文件。视频初始化、认证刷新、失败重试、资源切换、释放、播放／暂停／重新播放、拖动进度、静音和全屏路由逻辑均保持不变。视频宽高比及原有横向视频旋转逻辑不变，新的布局为画布预留独立空间。PDF 路由、加载、翻页、手势及原有页码更新逻辑保持不变。详见 [六项行为对比](behavior-checks.json) 与 [实现指纹](implementation-hashes.json)。共享反馈组件只增加可选按钮 key 和文案，原调用方默认行为不变。
