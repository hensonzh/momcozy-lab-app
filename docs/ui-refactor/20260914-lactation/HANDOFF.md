# 泌乳详情与记录弹窗

基于 [150 个已有截图状态](source-inventory.json)，完成 `/me/lactation` 详情页及妈妈页共用的泌乳记录弹窗重构。沿用妈妈页设计体系，先在 [Figma](https://www.figma.com/design/ePIoJkiMiXiug9ibpcgRbl?node-id=296-1086) 完成列表、趋势、泵奶／亲喂表单、长备注、加载、失败、确认与时间选择设计，再更新 Flutter。最终 [51 个 Figma 节点](figma-nodes.json) 包含 49 个状态画板与两个共享组件：MomCozy/LactationTrendCard（301:1086）、MomCozy/LactationRecordCard（301:1113）。

日期和原有奶滴图片组成简洁的顶部卡片，今日泵奶／亲喂摘要提前展示。趋势改为浅色卡片，保留 7／30 天切换和未记录日期留空。每条记录按方式、侧别、时间、数值、感受和备注分层，长备注使用整行宽度，编辑与删除移到卡片底部。普通和大字号使用同一组 Mom Design Tokens、卡片及按钮样式。

表单保留原字段、侧别选择、可选感受、2000 字备注、数值与时间校验。保存中的字段保持可读并阻止编辑；不确定保存仍锁定原提交内容并复用同一幂等键重试。保存、删除、撤销及错误反馈会自动滚动进入可见范围。为保证大字号下反馈能被定位，当天列表内容一起布局；此实现未做大量单日记录的性能基准测试。

本轮只改动三个生产文件：`lactation_panel.dart`、`lactation_chart.dart`、`lactation_page.dart`，增加一个详情页测试文件。控制器、仓库接口、数据模型、路由和共用时间选择器实现均未修改。[11 项行为对比](behavior-checks.json) 记录保存、重试、撤销、离开确认、字段绑定及趋势计算的保留情况。删除方法额外在失败后定位错误反馈；删除请求与成功回调条件保持不变。

时间选择保留普通字号的原生时钟拨盘／键盘切换及大字号的既有滚动输入模式。在实际 320 宽度检查中发现 SDK 输入弹窗有 40 像素水平滚动范围，会裁掉标题及错误文案；通过本页面局部主题的窄屏内边距修正，新增断言确认该范围为 0。没有改写时间解析、上午／下午或日期组合规则。
