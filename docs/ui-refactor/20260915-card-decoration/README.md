# Me 背景元素语言同步到四个模块

日期：2026-09-15。范围：Figma 设计调整及 Flutter App 同步，已热更新本地 Android 测试 App。此前 More 实现对齐的报告仍记录此次装饰补充前的设计基准。

## 结果

复用 Me 画板 `19:2` 已有的光晕、月牙、水滴、圆环、波纹和叶片，不新增独立 UI 画板。装饰位于卡片底层、靠边角、低透明度；图表数据区、日期网格、普通聊天气泡和表单输入区不增加装饰。

## 验证与实现说明

- 98 张候选画板在排除新增装饰子树后，原有节点数量、ID、名称、可见性、位置、尺寸及文字内容的校验值全部一致。
- 213 张目标卡片各有且只有一个 `decoration/me-family` 图层，均为绝对定位、底层、锁定，卡片裁切开启。
- 页面顶层数量保持 595，其中 575 个 Frame；UI 画板仍为清理后的 566 张，没有重建已删除的大字号或重复设计。
- More 两个日常管理卡中的 4 个 SettingsRow 实例移除不透明实例背景，由父卡片提供相同底色，使装饰可以透出。主组件未改动。
- Me 原始设计及专家卡已有装饰未修改。
- Figma 修改完成后，根据用户选择同步 Flutter；四模块卡片已采用本记录的背景规则。App 验证与边界见下文。

## 可追溯文件

- `plan.json`：213 个目标节点、状态画板及修改前结构校验值。
- `mutations.json`：新增图层 ID、原裁切值及实例背景覆盖的原值，可据此恢复。
- `verification.json`：覆盖检查与修改前后结构／文字校验值。
- `figma-decoration.js`：复用 Me 元素的具体尺寸、偏移、透明度与颜色规则；填入目标后幂等执行。
- `*-before.png` / `*-after.png`：四模块默认页前后截图；`me-before.png` 为参考页。

## Flutter 同步

- 新增共享 `MomCardBackground`，通过 `MomHomeSurface` / `MomSettingsCard.backgroundDecoration` 显式启用。所有装饰位于不参与布局的绝对定位层，忽略触摸并排除辅助功能语义。
- `card_decoration_*.svg` 来自同目录 Me 原始 SVG，仅将外层节点透明度归一为 1，由共享组件应用 Figma 的目标透明度；保留路径、填充透明度及尺寸比例。原 Me 资源未改动。
- Baby：首页知识卡、睡眠／尿湿／便便、喂养、测量、趋势标题区及睡眠监测说明。
- Cozymate：首次问候与共享结构化结果卡；聊天正文、输入、菜单等沿用原设计。
- Schedule：日历标题区、空日程、预约、任务、个人安排、折叠和展开的照护方案。
- More：账号正常／加载态与日常管理卡；专家卡保持已有装饰。
- 使用原有状态组件，因此加载、空态、错误恢复、变更后的内容及大字号会复用对应背景，无额外业务状态。
- 本轮仅同步背景元素。四模块之前已有的排版、控件、图标及测试数据差异没有在这轮重新审计，不能据此声称所有页面与 Figma 逐像素一致。
