# 行动确认与结果卡片

本轮复核 41 个已有截图状态，其中 39 个完成实现或与已完成共享设计核对，另有 2 个记录详情状态明确待处理。逐项范围见 [覆盖表](coverage.json)，不能将截图状态数视为页面数或全 App 完成比例。

按照已有截图、妈妈页设计语言、Figma、Flutter 的顺序推进。[Figma 行动确认设计](https://www.figma.com/design/ePIoJkiMiXiug9ibpcgRbl?node-id=284-1086) 包含普通和大字号下的待确认、确认中、拒绝中、成功、拒绝及失败状态；复用结果卡片、咨询授权和记录入口模式。[29 个节点](figma-nodes.json) 包含 28 个状态画板与 MomCozy/ActionReviewCard 共享组件（286:1109）。

行动面板按标题、状态和操作类型、说明、变更预览、确认／拒绝按钮重新组织。复用 Mom 的浅色卡片、薄荷状态底色、玫瑰色主操作、字体和间距；窄屏或大字号时按钮纵向排列。标题从“待处理动作”调整为“操作事项”，以适配执行后的结果状态。状态通过 live region 提供给辅助技术。

本轮生产代码仅修改 AgentActionPanel 及引入共享结果卡片的 import。该类之前和模型及其后全部生产代码与本轮修改前副本一致；请求、确认／拒绝处理、状态映射、事件映射、持久化和恢复逻辑未改。详见 [四项对比检查](behavior-checks.json) 与 [实现指纹](implementation-hashes.json)。已有结果卡片本轮复核和更新验证图，没有再次修改其生产实现。
