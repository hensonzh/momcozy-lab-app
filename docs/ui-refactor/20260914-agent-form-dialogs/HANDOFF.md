# 聊天表单弹窗

本轮处理 [34 个已有截图状态](source-inventory.json)，涵盖喂养偏好、恢复支持及售后工单表单，以及自动打开、草稿恢复和提交后返回状态。复用妈妈页的颜色、字体、输入框和按钮模式，在 [Figma](https://www.figma.com/design/ePIoJkiMiXiug9ibpcgRbl?node-id=276-1086) 建立普通和大字号表单设计，沉淀 MomCozy/AgentFormSection（276:2357）。[40 个节点](figma-nodes.json) 包含 39 个状态画板和 1 个共享组件。

填写区使用奶油底色，标题和底部操作区使用浅色表面。分组标题改为青色 13 字号，字段标签为 14 字号，输入与选项为 16 字号；移除分组横线和多选区域的外层边框，减少重复包围。选中选项采用薄荷底和青色边框。输入框、下拉菜单和按钮沿用 16 圆角，弹窗沿用共享的 24 圆角，关闭按钮和底部操作触控高度至少 44。见 [普通表单](figma/top.png)、[喂养偏好](figma/feeding.png) 和 [售后表单](figma/ticket.png)。

校验和提交失败提示增加图标、边框与留白，并作为 live region 提供给辅助技术。提交中和只读状态的长文本可换行展示；已选下拉内容保持正常文字对比度，仍然不可编辑。日期选择继续使用原共享控件及原日期范围，仅传入本轮表单的局部主题；大字号继续使用日期输入模式。见 [错误状态](figma/large-error.png) 和 [日期选择](figma/date.png)。

保留正常字号下固定标题与操作区、内容滚动的布局；窄屏大字号或键盘导致可用高度不足时，标题、字段和操作整体滚动。取消保留草稿，提交中阻止重复提交和退出，失败恢复编辑，成功关闭弹窗并允许只读查看。字段分组、默认值合并、其它选项编码、提交内容、日期格式、回调及自动打开生命周期通过 [六项代码行为对比](behavior-checks.json) 确认未变。
