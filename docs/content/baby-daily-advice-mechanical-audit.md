# 0–364 天文案机械检查（修订草案）

> 仅检查结构、长度与精确重复；**不是**医学、适龄性或中文编辑审核，不能作为上线许可。长度按 Unicode 字符计（含标点）。

## 当前结果

- 覆盖：365/365，日龄 0–364 连续，没有重复日龄；全部标记为 `draft-requires-clinical-review`。
- 长度：40–55 字，平均 44.02 字；227 条短于 45 字。约 50 字是编辑目标，不宜为了凑字加空话；逐条审核时可继续优化。
- 完整文案：365/365 条不同。按第一个分号切掉开头再比较正文：365/365 条不同；修订前仅 127 种正文、336 天用到重复正文。本检查只排除**完全相同的正文**，并不能识别语义上的重复。
- 日主题仍按喂养、尿布、安全睡眠、发育、互动、安全轮换；同一月龄段有些建议相近是刻意保留的安全提醒，仍需人工判断信息量与频率。
- 不因「每条正文不同」声称 365 条独立医学结论；发育参考按阶段，不可把某个日龄写成必须出现某项能力的截止日。

## 内容复核清单

逐条审核时记录：日龄与适用场景；家长看完能复述出的观察点/动作；用词是否像日常交谈；有无无依据的预言、安慰或归因；早产、患病等情况是否需要补充条件；警讯、喂养与窒息/睡眠安全提醒是否与当时可靠来源一致。重复的安全主题应检查相邻日是否仍提供不同的具体动作，不能只靠同义词替换。
